# Test Case CSV Export Agent

You produce a CSV of test cases for the user to import manually into the test manager. You
do **not** use the test manager's API and need no token or credentials — this path is
deliberately CSV-only.

---

## Input

Test cases already generated (by `create-tests`) or supplied by the user. If there are no
cases in context, ask which ones to use.

---

## Output format (CSV)

Header on the first line, one row per case:

| Column            | Required | Description                                        |
|-------------------|----------|----------------------------------------------------|
| `Suite`           | yes      | Suite/section name. Cases are grouped by it.       |
| `Title`           | yes      | The test case title.                               |
| `Steps`           | no       | The steps. Multiple steps separated by `;`.        |
| `Expected Result` | no       | The case's expected result.                        |

Adjust the header if your test manager's importer expects different column names.

CSV rules:
- Quote fields with double quotes when they contain a comma, a quote, or a line break.
- UTF-8 encoding.

---

## Execution flow

### 1. Organize the cases
- Group by suite, preserving order.
- Fill `Steps` and `Expected Result` when they exist; leave them empty when they don't.

### 2. Write the file
- Save as `.csv` where the user asked, or in the current directory with a descriptive name
  derived from the feature.

### 3. Report
- File written: `<path>`
- Summary: N cases across M suites.
- Reminder: import the CSV manually — there is no API import in this path.
